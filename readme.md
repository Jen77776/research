# AI Alignment Research OS

这套系统分两层：
- `AI_Alignment_Research_OS.xlsx`：研究总览、主动回忆、研究问题管理。
- `paper_note_template.md`：值得深入掌握的论文再写一页 Deep Note。
- `sorensen24a_starter_note.md`：正在学习论文的**起步草稿**，不是经核对的论文摘要。

## 立即开始（15 分钟）
1. 打开表格 `02_主动回忆`，任选 2 个问题闭卷回答。
2. 看 `01_论文追踪` P003，填写“上次阅读”和“下次具体动作”。
3. 复制 `paper_note_template.md` 到自己的 `papers/论文名.md`。
4. 每次读完只做 3 件事：更新论文一行、留 1 个闭卷问题、写 1 个下次动作。

## 复习怎么更新？
先在 `02_主动回忆` 的 D 列回答问题，再评估掌握度。
在 G 列填本次复习日期，在 H 列填间隔天数：1 / 3 / 7 / 14。
I、J 列会自动计算下次复习日与是否到期。无需手动改 I、J。

## Google Sheets / GitHub
- 将 .xlsx 上传 Google Drive 并在 Google Sheets 打开，即可用在线表格。
- Markdown 可用 VS Code 编辑，保存在私人 GitHub 仓库中。
- 不必每天整理 GitHub。重要论文/困难概念才使用 Markdown 深度笔记。
- iPad 适合 PDF 划线，但关键内容最终要进可检索的表格/笔记。

## 数据提醒
预填内容只作为示例。理解度、阅读日期等个人学习进展需自行更新；
Research Questions 均属尚未通过文献核实的思考方向。
